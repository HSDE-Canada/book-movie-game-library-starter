# Week 3 - Book, Movie, or Game Library

## Project Goal
Build a Book, Movie, or Game Library that displays a collection of media items from JavaScript data.

This project focuses on arrays, objects, loops, filtering, and rendering.

## Instructions
Work in the `starter` folder of this repository.

## Challenges

1. Add at least two more objects to the `libraryItems` array.
2. Select the library grid element.
3. Select the stats bar element.
4. Select the search input element.
5. Select the page title element.
6. Select the page subtitle element.
7. Update the page title using `categoryInfo` and `currentCategory`.
8. Update the page subtitle using `categoryInfo` and `currentCategory`.
9. Complete the category filter comparison.
10. Write the full `for` loop setup.
11. Display the item’s `coverClass` property.
12. Display the item’s `coverTitle` property.
13. Display the item’s `coverSubtitle` property.
14. Display the item’s `coverIcon` property.
15. Display the item’s `title` property.
16. Display the item’s `creator` property.

## Extension Challenges
Personalize the library content, cover icons, colors, statuses, and category subtitles after the required app works.
